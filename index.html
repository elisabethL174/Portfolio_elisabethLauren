03 — Undergraduate Thesis

An educational game for early childhood

Unity · C# · Undergraduate Thesis

Rancang Bangun Game Edukasi Pengenalan Huruf, Angka, dan Hewan untuk Anak Usia Dini

A learning game that teaches preschool children to recognise letters, numbers, and animals through play. Built in Unity for Android and Windows.

The core design problem: children memorise positions, not content. If the answer is always in the same place, a child learns the pattern instead of the letter. I used the Fisher-Yates shuffle to randomise question and answer order on every run — an unbiased shuffle where every arrangement is equally likely, so no sequence can be learned by repetition. The child has to actually recognise the character to get it right.

Unbiased randomisationEvery permutation equally likely — no learnable pattern
Built for small handsLarge touch targets, audio cues, no text instructions required
